X 媒体下载器 v1.0.1（Windows 64 位 便携版）
=================================================

【怎么运行】
  双击文件夹里的  X媒体下载器.exe  →  直接打开图形界面，不需要安装 Python。
  注意：exe 和 _internal 文件夹是一体的，请整个文件夹一起保留 / 移动，不要只拷 exe。

【首次使用三步】
  1. 先开代理。程序会自动读取本机系统代理；不确定就点「自动检测」——
     它会挨个测试常见的本地代理端口（7890 / 7897 / 10809 / 10808 / 1080 …），
     哪个能连上 X 就自动填进去。也可以手动填，或者留空表示不指定代理。
  2. 点「① 打开浏览器登录 X」→ 会弹出一个独立浏览器窗口，在里面正常登录 X。
  3. 点「② 读取登录 Cookie」→ 状态行显示「已登录 @你的账号」就准备好了。
     （登录一次长期有效，下次直接开始下载即可）

【日常使用】
  ① 选择下载文件夹：界面下方「下载到：」那一行点「📁 选择文件夹…」，
     选好之后所有下载文件都存到这里（程序会自动在下面按推文日期建子文件夹）。
     也可以勾上「下载完成后自动打开文件夹」。
  ② 填搜索关键词（每行一个，支持 from:user / filter:images 等 X 高级语法）
  ③ 填日期区间（YYYY-MM-DD，或点「最近7天」「最近30天」）
  ④ 点「▶ 开始搜索并下载」

  下载结果示例：
      你选的文件夹\2024-05-01\alice_1800000000000000001_01.jpg
      你选的文件夹\2024-05-03\bob_1800000000000000002_01.mp4
  另外 _meta\downloads.csv 里有完整清单（日期 / 作者 / 推文链接 / 文件名 / 大小 / 源地址）。

【自检】
  命令行执行：  X媒体下载器.exe --selftest
  结果写在同目录的 selftest-report.txt（44 项，含真浏览器端到端抓取验证）。

【常见问题】
  连不上 X            → 点「自动检测」；或确认代理客户端已启动、端口填对，再点「测试连通性」
  日志提示未登录      → 先在浏览器窗口登录 X，再点「② 读取登录 Cookie」
  日志提示配置目录被占用 → 上次那个浏览器还开着。关掉它，或点「结束残留浏览器」
  提示"兼容模式启动"  → 你的系统拦了 Chrome 自带沙箱，程序已自动切换兼容模式，功能不受影响
  视频存成 .ts        → 该视频只有 HLS 流，PotPlayer / VLC 可直接播放
  想重新下一遍        → 取消勾选「跳过已下载」

【文件说明】
  X媒体下载器.exe     主程序（双击运行）
  _internal\          运行库（别删、别单独移动）
  config.json         界面设置（自动生成；开"自动读取系统代理"时不写死代理地址）
  cookies.json        登录 Cookie（自动生成，别外传）
  _browser_profile\   程序专用浏览器配置目录（登录态存在这里；删掉=退出登录）
  使用说明.txt / 技术文档.md
