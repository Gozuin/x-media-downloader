# X 媒体下载器

**按关键词搜索 X（推特），把指定日期区间内的视频/图片批量下载下来，按日期自动分文件夹。**

Windows 桌面程序 · 中文界面 · 双击即用 · 不需要装 Python

---

## 一句话

想存 X 上某个话题的图/视频，官方没有批量下载；别的工具只能按"某个账号的全部媒体"下，或者要你自己折腾 API。

**这个工具让你像用搜索一样下载**：填关键词 + 日期区间 → 点「开始」→ 按日期分好文件夹。

## 三个亮点

| | |
|---|---|
| **不会因为"动态签名"失效** | 用真实的 Chrome 自己发请求，程序只读响应。X 改版基本不用跟着改 |
| **不容易被封号** | 全局限流 · 失败风暴自动降速 · 429 退避 · 地址形状自适应剪枝（少发一半无用请求）· 抓取结果缓存复用 |
| **下载结果整齐** | `输出目录/2024-05-01/作者_推文ID_01.mp4`，另附 CSV 清单 |

## 30 秒跑起来

```
1. 解压发布包 → 双击 X媒体下载器.exe
2. 点「打开浏览器登录」→ 在弹出的 Chrome 里登录 X → 回来点「读取登录 Cookie」
3. 填关键词（如 `飞机`）+ 日期区间 → 点「开始搜索并下载」
```

> 需要能访问 X 的网络环境（一般要挂代理）。程序里可填代理地址，点「测试连通性」确认。

## 它到底做什么

| 你想要的 | 程序里的实现 |
|---|---|
| 不用手抄 Cookie | 「① 打开浏览器登录 X」→「② 读取登录 Cookie」：用**独立配置目录**拉起真实 Chrome/Edge，你正常登录，程序通过调试协议读出 Cookie 并**实测确认已登录**（显示 @账号）。不碰你日常浏览器 |
| 按搜索结果下 | 关键词框（一行一个），支持 X 高级语法：`from:user`、`filter:images`、`"完整短语"`、`min_faves:100`；可选「最新 / 热门」页签 |
| 只要某个日期段 | 日期区间填 `YYYY-MM-DD`：**同时**写进搜索语句（`since:` / `until:`，服务端先过滤）**和**下载前的本地二次过滤（按推文发布时间，可选本地时区 / UTC） |
| 视频和图片 | 视频 → 最高码率 mp4；动图 → mp4；图片 → 原图 `?name=orig`，取不到时自动回退 4096x4096 / large / medium |
| 结果分类整齐 | 按推文日期建文件夹；另存 `_meta/downloads.csv`（时间/日期/作者/推文链接/类型/文件名/大小/源地址）；失败的写 `_meta/failed.csv`（含每个候选地址的 HTTP 状态） |
| 简单好用的界面 | 纯 Python + tkinter，无内置浏览器内核。打包后双击即用 |

## 跑起来

**方式一：直接用打包好的程序（推荐）**

从 [Releases](https://github.com/Gozuin/x-media-downloader/releases) 下载 `X媒体下载器-vX.Y.Z-win64.zip`，解压后双击 `X媒体下载器.exe`。**不需要装 Python。**

**方式二：跑源码**

```bash
pip install -r requirements.txt
python main.py                # 启动图形界面
python main.py --selftest     # 自检：70 项，含真浏览器端到端抓取
```

**环境**：Python 3.10+（打包用 3.12）。依赖只有三个：`requests`、`websocket-client`、`cryptography`。

**自己打包**（Windows）：

```bat
build_exe.bat                  :: 生成图标 + PyInstaller 打包到 dist\
python build\package_release.py :: 跑打包版自检，再组装发布 zip
```

### 打包相关的两个环境适配（已内建，遇到会自动处理）

| 现象 | 原因 | 程序的处理 |
|---|---|---|
| 日志出现「以 --no-sandbox 方式启动浏览器（受限环境兼容模式）」 | 部分沙箱/EDR 环境会拦掉 Chrome 自带沙箱，Chrome 启动瞬间以 `0x80000003` 退出 | 先用常规参数启动；失败自动换 `--no-sandbox` 重试，过程写进日志 |
| 打包版用 `--windowed` 会在某些加固环境被直接杀掉 | GUI 子系统进程受限 | 改用**控制台子系统**打包，程序启动后自己把控制台窗口藏起来（外观与普通窗口程序一致），兼容性最好 |

> 打包用 Python 3.12（Tk 8.6）。用 Python 3.14 + Tcl/Tk 9.0 打包时 PyInstaller 会漏收 `_tcl_data`/`_tk_data`，界面起不来。

## 使用步骤

1. **开代理**（Clash 之类），程序里点「测试连通性」确认正常。
2. **① 打开浏览器登录 X** —— 弹出独立 Chrome 窗口（用程序自带的 `_browser_profile` 目录，不碰你日常浏览器）。正常登录，2FA 照常走。
3. **② 读取登录 Cookie** —— 成功后状态行显示 `Cookie：auth_token✓/ct0✓/twid✓ · 登录：已登录 @你的账号`。
   *不想用程序开浏览器？也可以从自己浏览器 F12 → Network 里复制整段 Cookie 粘到「手动 Cookie」，点「应用」。*
4. **填搜索条件**：关键词（可多行）、日期区间（可点「最近 7 天 / 30 天」）、页签、内容类型、翻页上限、并发数。
5. **选保存位置**（默认 `C:\Users\<你>\Downloads\X媒体下载`）。
6. **▶ 开始搜索并下载** —— 进度与日志实时显示「抓到多少推文 / 下载多少 / 失败多少」，随时可「■ 停止」。

下载完成后：

```
X媒体下载/
├─ 2024-05-01/
│   ├─ alice_1800000000000000001_01.jpg
│   └─ bob_1800000000000000002_01.mp4
├─ 2024-05-03/
│   └─ carol_1800000000000000003_01.mp4
└─ _meta/
    ├─ downloads.csv     # 下载清单
    └─ failed.csv        # 失败的每个候选地址 + HTTP 状态
```

## 它是怎么做到的

```
① 登录   Chrome --remote-debugging-port  →  CDP 读 Cookie + 页面实测登录状态
② 抓取   接管同一个浏览器 → 打开 x.com/search → 拦截 SearchTimeline 响应（滚动翻页）
③ 解析   深度容错解析推文 JSON → 作者/时间/媒体；转推自动取原推；时间缺失用雪花 ID 反推
④ 过滤   since/until 服务端过滤 + 本地按发布时间二次过滤
⑤ 下载   多线程（默认 8）→ 按日期归档 → 图片 404 自动回退尺寸 → 失败重试 → 断点跳过
⑥ 防封   全局限流 + 失败风暴自动降速 + 429 退避 + 地址形状剪枝 + 抓取缓存复用
```

**为什么走浏览器抓包，而不是直接调 X 的接口？**

X 的 GraphQL 接口要求 `x-client-transaction-id` 这类动态签名头，纯脚本模拟很容易失效；让真实浏览器自己发请求、我们只读响应，最稳，也最扛改版。

**兜底**：接口一条都没拦到时，自动改用页面 DOM 提取媒体；视频若只有 HLS 分片，会自动拉齐分片合并（加密分片用 AES-128 解密）。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 「测试连通性」失败 | 代理没开，或端口填错 |
| 日志报「页面像是未登录状态」 | 先在浏览器窗口里登录 X，再点「② 读取登录 Cookie」 |
| 抓不到推文、`接口命中 0 次` | X 改版或触发风控。程序会自动用 DOM 兜底；也可能是搜索被限流，隔 10~30 分钟再试 |
| 页面显示 `Something went wrong` | X 的搜索接口被限流，不是程序问题。停一会儿，手动刷新搜索页能出推文了再跑 |
| 下载全部失败、`WinError 5 拒绝访问` | 程序进程权限过低（低完整性级别）。**直接双击 exe 启动**，或右键「以管理员身份运行」 |
| 老视频下成 `.ts` 而不是 `.mp4` | 该视频只有 HLS 流。`.ts` 用 PotPlayer/VLC 可直接播；装了 ffmpeg 可 `ffmpeg -i x.ts -c copy x.mp4` 转封装 |
| 图片下载失败 | 极老的推文没有 `orig` 尺寸，程序已自动回退多档；仍失败会记进 `_meta/failed.csv` |
| 想重新下一遍 | 取消勾「跳过已下载」（同名文件自动加 `_2`） |
| 登录态丢了 | 浏览器窗口里重新登录，再点「② 读取登录 Cookie」 |

## 文件说明

```
x-media-downloader/
├─ main.py                 入口（GUI / --selftest）
├─ run.bat                 双击启动（源码方式）
├─ build_exe.bat           一键打包
├─ requirements.txt        依赖
├─ LICENSE                 许可证（MIT）
├─ config.json             界面设置（自动生成，不入库）
├─ cookies.json            登录 Cookie（自动生成，不入库，别外传）
├─ _browser_profile/       程序专用浏览器配置目录（登录态存这里，不入库）
├─ xdl/
│   ├─ gui.py              图形界面
│   ├─ pipeline.py         任务编排：多关键词 → 抓取 → 过滤 → 下载
│   ├─ harvest.py          搜索页驱动 + 接口拦截 + DOM 兜底 + 滚动翻页
│   ├─ parse.py            推文/媒体解析、日期过滤、搜索语句拼装、图片候选地址链
│   ├─ download.py         多线程下载、按日期归档、HLS 合并、断点去重、限流
│   ├─ cache.py            抓取结果缓存（复用 = 完全不碰搜索接口）
│   ├─ browser.py          浏览器启动、Cookie 读取、登录验证、连通性测试
│   ├─ cdp.py              极简 Chrome DevTools Protocol 客户端
│   ├─ util.py             时间 / 文件名 / 日志 / 配置工具
│   └─ selftest.py         70 项自检
├─ build/                  打包脚本、图标、版本信息、发布组装
└─ _shots/                 界面截图
```

> Cookie 只存在本机，程序不会上传到任何地方。想清掉直接删 `cookies.json` 与 `_browser_profile/`。
