# X 媒体下载器（X Media Downloader）

Windows 桌面程序（tkinter 图形界面）：**从网页取 X 登录 Cookie → 跑指定搜索结果 → 下载指定日期区间内的视频和图片 → 按日期分文件夹保存。**

---

## 一、它到底做什么

| 你要求的功能 | 程序里的实现 |
|---|---|
| 从网页获取 X 的登录 cookie | 「① 打开浏览器登录 X」→「② 读取登录 Cookie」：用独立配置目录拉起真实 Chrome/Edge，你在窗口里正常登录，程序通过调试协议把 Cookie 读出来并**实测确认已登录**（显示 @账号） |
| 用指定的搜索结果 | 「搜索关键词」框填词（一行一个，支持 `from:user`、`filter:images`、`"完整短语"`、`min_faves:100` 等 X 高级语法），选「最新/热门」页签 |
| 下载指定日期之内的 | 「日期区间」填 `YYYY-MM-DD`：**同时**写进搜索语句（`since:` / `until:`，服务端先过滤）和下载前的本地二次过滤（按推文发布时间） |
| 视频和图片 | 视频 → 最高码率 mp4；动图 → mp4；图片 → 原图 `?name=orig`（不存在时自动回退 4096x4096/large/medium） |
| 下载结果按日期保存到文件夹 | `输出目录/2024-05-01/alice_1800000000000000001_01.jpg`；另存 `_meta/downloads.csv` 记录清单 |
| 电脑端程序 + 简洁 GUI | 纯 Python + tkinter，零安装（依赖 `requests`、`websocket-client`），双击 `run.bat` 即用 |

## 二、跑起来

**方式一（推荐）：直接用打包好的程序**
```
dist\X媒体下载器-v1.0.0-win64.zip     ← 解压后双击「X媒体下载器.exe」，不需要装 Python
python build_exe.bat                  ← 想自己重新打包就跑这个
```

**方式二（开发调试）：跑源码**
```
python main.py                      # 启动图形界面
python main.py --selftest           # 自检（44 项，含真浏览器端到端抓取）
```

**依赖**：Python 3.10+，`requests`、`websocket-client`（HLS 加密分片另需 `cryptography`）。
缺了就跑：`python -m pip install requests websocket-client cryptography`

**必备**：能连上 X 的网络环境（代理）。程序里填代理地址（默认读你系统的 `127.0.0.1:7890`），点「测试连通性」确认。

### 打包相关的两个环境适配（已内建，遇到会自动处理）

| 现象 | 原因 | 程序的处理 |
|---|---|---|
| 日志出现「以 --no-sandbox 方式启动浏览器（受限环境兼容模式）」 | 部分沙箱/EDR 环境会拦掉 Chrome 自带沙箱，Chrome 启动瞬间以 `0x80000003` 退出 | 先用常规参数启动；失败自动换 `--no-sandbox` 重试并把过程写进日志 |
| 打包版用 `--windowed` 会在某些加固环境被直接杀掉 | GUI 子系统进程受限 | 改用**控制台子系统**打包，程序启动后自己把控制台窗口藏起来（外观与普通窗口程序一致），兼容性最好 |

> 打包用的是 Python 3.12（Tk 8.6）。用 Python 3.14 + Tcl/Tk 9.0 打包时 PyInstaller 会漏收 `_tcl_data`/`_tk_data`，导致打包版界面起不来。

## 三、使用步骤

1. **开代理**（你的 Clash / 其它客户端），程序里「测试连通性」应显示正常。
2. **① 打开浏览器登录 X** —— 会弹出一个独立 Chrome 窗口（用程序自带的 `_browser_profile` 配置目录，不碰你日常浏览器）。在里面正常登录 X；用两次验证码/2FA 都照常走。
3. **② 读取登录 Cookie** —— 程序自动读 Cookie 并跳主页验证，成功后状态行显示 `Cookie：auth_token✓/ct0✓/twid✓ · 登录：已登录 @你的账号`。
   *（不想用程序开浏览器？也可以从自己浏览器的 F12 → Network 里复制整段 Cookie 粘到「手动 Cookie」一行，点「应用」。）*
4. **填搜索条件**：关键词（可多行）、日期区间（可点「最近7天/最近30天」）、页签、要下载的内容类型、翻页/推文上限、并发数。
5. **选保存位置**（默认 `C:\Users\<你>\Downloads\X媒体下载`）。
6. **▶ 开始搜索并下载** —— 进度条与日志实时显示「抓到多少推文 / 下载多少 / 失败多少」，随时可「■ 停止」。

下载完成后打开保存目录，会看到按日期分的文件夹：

```
X媒体下载/
├─ 2024-05-01/
│   ├─ alice_1800000000000000001_01.jpg
│   └─ bob_1800000000000000002_01.mp4
├─ 2024-05-03/
│   └─ carol_1800000000000000003_01.mp4
└─ _meta/downloads.csv        # 下载清单：时间/日期/作者/推文链接/类型/文件名/大小/源地址
```

## 四、程序怎么做到的（技术要点）

```
① 浏览器登录  Chrome --remote-debugging-port  ─→ CDP 读 Cookie + 页面实测登录状态
② 抓搜索结果  接管同一个浏览器 → 打开 x.com/search → 拦截 SearchTimeline 接口响应（滚动翻页）
③ 解析        深度容错解析推文 JSON → 作者/时间/媒体；转推自动取原推；时间缺失用雪花 ID 反推
④ 日期过滤    since/until 服务端过滤 + 本地按推文发布时间二次过滤（本地时区或 UTC 可选）
⑤ 下载        多线程（默认 8）→ 按日期归档 → 404 自动回退图片尺寸 → 失败重试 3 次 → 断点跳过
```

**为什么走浏览器抓包而不是直接调 X 接口？**
X 的 GraphQL 接口要求 `x-client-transaction-id` 这类动态签名头，纯脚本模拟很容易失效；让真实浏览器自己发请求、我们只读响应，最稳、也能长期可用。

**兜底机制**：接口一条都没拦到时，会自动改用页面 DOM 提取媒体（`DOM 兜底` 勾选项），视频若是 HLS 分片会自动拉齐 `.ts` 合并（加密分片用 AES-128 解密）。

## 五、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 「测试连通性」失败 | 代理没开，或代理端口填错。改端口后重试 |
| 日志报「页面像是未登录状态」 | 先在浏览器窗口里登录 X，再点「② 读取登录 Cookie」 |
| 抓不到推文、`接口命中 0 次` | X 改版或触发风控；把日志发我。程序会自动用 DOM 兜底 |
| 老视频下成 `.ts` 而不是 `.mp4` | 该视频只有 HLS 流（接口没给 mp4）。`.ts` 用 PotPlayer/VLC 可直接播；装个 ffmpeg 后可 `ffmpeg -i x.ts -c copy x.mp4` 转封装 |
| 图片下载失败 | 极老的推文没有 `orig` 尺寸，程序已自动回退多档尺寸；仍失败会记在日志的失败明细里 |
| 想重新下一遍 | 取消勾「跳过已下载」即可（同名文件会自动加 `_2`） |
| 登录态丢了 | 浏览器窗口里重新登录一次，再点「② 读取登录 Cookie」 |

## 六、文件说明

```
x-media-downloader/
├─ main.py                入口（GUI / --selftest）
├─ run.bat                双击启动
├─ config.json            界面设置（自动生成）
├─ cookies.json           登录 Cookie（自动生成，**别外传**）
├─ _browser_profile/      程序专用浏览器配置目录（登录态存在这里）
├─ xdl/
│   ├─ gui.py             图形界面
│   ├─ pipeline.py        任务编排：多关键词 → 抓取 → 过滤 → 下载
│   ├─ harvest.py         搜索页驱动 + 接口拦截 + DOM 兜底 + 滚动翻页
│   ├─ parse.py           推文/媒体解析、日期过滤、搜索语句拼装
│   ├─ download.py        多线程下载、按日期归档、HLS 合并、断点去重
│   ├─ browser.py         浏览器启动、Cookie 读取、登录验证、连通性测试
│   ├─ cdp.py             极简 Chrome DevTools Protocol 客户端
│   ├─ util.py            时间/文件名/日志/配置工具
│   └─ selftest.py        44 项自检
└─ _shots/ui.png          界面截图
```

> Cookie 文件只存在本机，程序不会上传任何地方；用完想清掉直接删 `cookies.json` 与 `_browser_profile/`。
